# 压缩

一个 SillyTavern 扩展：**上下文太长，token 烧得肉疼** → 一键把前文压缩成一段"记忆摘要"。

---

## 功能：压缩前文

聊到几百楼，前面的剧情又不舍得删？让模型帮你"记笔记"。

**两种模式：**

- **手动模式（默认）**：想压的时候再压。三个入口任选——
  - 输入框旁的 **"选项"菜单**（就是"重新生成 / AI帮答 / 续写"那个菜单）里的 **「压缩上下文」**
  - 设置面板里的 **「立即压缩」** 按钮
  - 命令 `/compress`
- **自动模式**：在设置里打开后，达到触发条件就自动压缩一次。开着自动模式也随时可以手动压。

两种模式压的范围都是**上一次压缩点之后的全部消息**——不重复压、不漏压。想只压最近几条也行：`/compress 20`，或在按钮旁的小框里填条数。

自动模式的触发条件有两种：**按用户输入条数**（默认每 10 条，编辑重发不算数）或**按历史 token 数**（默认 12000，可在设置里改）。设置面板里会实时显示当前计数 / token 数。

**自动压缩规则**：可限定只有主对话当前的**补全源**、**代理预设**、**模型**同时满足时才自动压缩（手动压缩不受限）。默认补全源 `claude`、代理预设 `all`、模型 `claude`。`all` 表示不限；模型为宽松匹配，填 `claude` 即匹配名称中包含 claude 的任何模型（忽略大小写）。代理预设同样只能从 ST 已有的代理预设中选择。

**保留最近 N 条不压缩**：手动压缩和自动压缩分开设置（默认手动保留 2 条、自动保留 4 条；手动指立即压缩按钮、选项菜单按钮和 /compress），最后 N 条消息就不参与压缩，原样留在摘要后面，保证模型手边始终有最近几轮的原文细节；下次压缩时它们再被纳入。指定条数压缩时按手动的保留条数生效。

- 压缩结果作为一条"记忆摘要"写回聊天
- **之前的摘要也发送并合并**（默认勾选）：紧挨本次压缩范围的上一条摘要会一起发给模型，合并成一条新摘要，旧摘要随原始消息一起隐藏，聊天里始终只留一条有效摘要
- 勾选「压缩后隐藏原始消息」的话，被压缩的原文会自动灰显、不再发给模型——记录还在，token 省了

**可以自己调的东西**：压缩提示词（默认为英文通用提示词，摘要会跟随对话语言）、自动压缩的触发条数或 token 阈值、摘要以什么角色写回、摘要开头的标记文字。

**使用主路径预设**：压缩参数里可单独开启，默认关闭。开启后会带上当前主对话的预设、世界书和上下文，压缩提示词仍然生效，摘要范围仍以选中的消息为准；关闭时只发送压缩提示词和待压缩消息。两种方式默认都使用当前连接的模型，开启「自定义连接」后改用那里指定的源 / 代理 / 模型。

**自定义连接（源 / 代理预设 / 模型）**：默认关闭。开启后压缩不再用主对话的连接，而是走你指定的**源**（Claude / OpenAI / Custom 等）、**代理预设**（ST 里带 url 和账号密码的那条代理记录；只能从已有代理预设中选，不支持手填 url / 密码）和**模型**。压缩的两种模式都生效：主路径下提示词仍由完整管线构建，只替换连接；直连路径则整条请求都走自定义连接。适合"压缩丢给便宜模型、主对话照旧用贵的"这类玩法。

注意这里说的「代理预设」是 ST 的**代理**记录（Connection Profiles 用的那个 `proxies` 列表），**不是**破限 / 提示词预设——提示词预设是下面那个「用预设」下拉框。

**模型**：一个普通下拉框，跟上面的「源」一样，换源时会跟着刷新，选「跟随该源的当前模型」就沿用该源当前的模型。

候选就是该源在 ST 里那个模型下拉里的内容，包括 OpenAI 源下由接口提供的 **External** 模型（不必在 ST 里勾「Show External models」也能选到）。候选是在展开下拉时现读的，所以 ST 异步加载进来的模型不用刷新页面也能看到。

如果下拉里空空如也，说明 ST 还没连过那个源、没加载过它的模型列表——先在 ST 里连一次即可。

**指定预设**：压缩有一个「用预设」下拉框，默认"跟随当前预设"。选了别的 Chat Completion 预设后，执行时会临时切过去、完成后自动切回——开启主路径时用它的提示词和参数，关闭时只用它的采样参数；如果开了 ST 的"预设绑定连接"，预设里的源/模型也会一起切换（可以拿来让压缩走便宜模型）。注意：切换预设会重新载入预设文件，**当前预设没保存的改动会丢失**，请先保存。

## 常见问题

**压缩会把原文删掉吗？**
不会。原文只是灰显、不再发给模型，聊天记录里随时能看。不想隐藏的话把勾去掉即可。

**压缩用的是哪个模型？**
默认是你当前连接的模型；开「自定义连接」后则是那里指定的源 + 代理 + 模型。

**摘要会累积很多条吗？**
不会。默认会把紧挨着的上一条摘要一起发送并合并，旧摘要随原文一并隐藏，聊天里始终只留一条有效摘要。想保留多条历史摘要的话，把「之前的摘要也发送并合并」的勾去掉即可。
