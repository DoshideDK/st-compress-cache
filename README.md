# 压缩与改写

一个 SillyTavern 扩展，帮你解决长对话的两大烦恼：

- **上下文太长，token 烧得肉疼** → 一键把前文压缩成一段"记忆摘要"
- **最后一条回复差点意思，重 roll 又是开盲盒** → 用一句话指令局部改写，只改不满意的部分

---

## 安装

1. 打开 SillyTavern 的 **扩展面板** → **Install extension**
2. 粘贴本仓库地址：`https://github.com/LeenHawk/st-compress-cache`
3. 装好后刷新页面，扩展面板里会出现「**压缩与改写**」设置抽屉

---

## 功能一：压缩前文

聊到几百楼，前面的剧情又不舍得删？让模型帮你"记笔记"。

**两种模式：**

- **手动模式（默认）**：想压的时候再压。三个入口任选——
  - 输入框旁的 **"选项"菜单**（就是"重新生成 / AI帮答 / 续写"那个菜单）里的 **「压缩上下文」**
  - 设置面板里的 **「立即压缩」** 按钮
  - 命令 `/compress`
- **自动模式**：在设置里打开后，你每发满 N 条消息（默认 10 条，编辑重发不算数），AI 回复完就自动压缩一次。开着自动模式也随时可以手动压。

两种模式压的范围都是**上一次压缩点之后的全部消息**——不重复压、不漏压。想只压最近几条也行：`/compress 20`，或在按钮旁的小框里填条数。

**保留最近 N 条不压缩**：设置里填一个数（默认 0），最后 N 条消息就不参与压缩，原样留在摘要后面，保证模型手边始终有最近几轮的原文细节；下次压缩时它们再被纳入。手动、自动和指定条数压缩都生效。

- 压缩结果作为一条"记忆摘要"写回聊天
- 勾选「压缩后隐藏原始消息」的话，被压缩的原文会自动灰显、不再发给模型——记录还在，token 省了

**可以自己调的东西**：压缩提示词（默认为英文通用提示词，摘要会跟随对话语言）、自动压缩的触发条数、摘要以什么角色写回、摘要开头的标记文字。

**使用主路径预设**：压缩参数里可单独开启，默认关闭。开启后会带上当前主对话的预设、世界书和上下文，压缩提示词仍然生效，摘要范围仍以选中的消息为准；关闭时只发送压缩提示词和待压缩消息。两种方式默认都使用当前连接的模型，开启「自定义连接」后改用那里指定的源 / 代理 / 模型。

**自定义连接（源 / 代理预设 / 模型）**：压缩和改写各有一块，默认关闭。开启后这一项任务不再用主对话的连接，而是走你指定的**源**（Claude / OpenAI / Custom 等）、**代理预设**（ST 里带 url 和账号密码的那条代理记录，也可以直接手填 url 和密码覆盖它）和**模型**。压缩的两种模式都生效：主路径下提示词仍由完整管线构建，只替换连接；直连路径则整条请求都走自定义连接。适合"压缩丢给便宜模型、主对话照旧用贵的"这类玩法。

注意这里说的「代理预设」是 ST 的**代理**记录（Connection Profiles 用的那个 `proxies` 列表），**不是**破限 / 提示词预设——提示词预设是上面那个「用预设」下拉框。

**模型**：一个普通下拉框，跟上面的「源」一样，换源时会跟着刷新，选「跟随该源的当前模型」就沿用该源当前的模型。

候选就是该源在 ST 里那个模型下拉里的内容，包括 OpenAI 源下由接口提供的 **External** 模型（不必在 ST 里勾「Show External models」也能选到）。候选是在展开下拉时现读的，所以 ST 异步加载进来的模型不用刷新页面也能看到。

如果下拉里空空如也，说明 ST 还没连过那个源、没加载过它的模型列表——先在 ST 里连一次即可。

**指定预设**：压缩和改写各有一个「用预设」下拉框，默认"跟随当前预设"。选了别的 Chat Completion 预设后，执行时会临时切过去、完成后自动切回——开启主路径时用它的提示词和参数，关闭时只用它的采样参数；如果开了 ST 的"预设绑定连接"，预设里的源/模型也会一起切换（可以拿来让压缩走便宜模型）。注意：切换预设会重新载入预设文件，**当前预设没保存的改动会丢失**，请先保存。

## 功能二：改写上一条

最后一条 AI 回复整体不错，就是某段不满意？不用重 roll 开盲盒，也不用自己动手编辑。

**用法：**

1. 在输入框写下改写要求，比如"把结尾那段改含蓄一点"
2. 点 **"选项"菜单** 里的 **「改写上一条」**（或用命令 `/rewrite 把结尾那段改含蓄一点`）
3. 模型按所选预设模式改写最后一条回复，改完直接替换

**使用主路径预设**：改写设置里可单独切换，默认开启，沿用完整的主对话提示词构建流程。关闭后只带未隐藏的聊天内容和改写指令，不带主路径的预设、世界书等提示词。两种方式下，改写提示词和输出格式设置都继续生效。

**几个贴心的地方：**

- **指令不进聊天记录**——它只存在于那一次请求里
- **原文自动存为 swipe**——改坏了左滑就能找回
- **默认局部替换模式**：模型只输出改动的片段（搜索替换块），扩展在本地应用——省输出 token，且不会顺手改掉你满意的部分。在设置里可以关掉，关掉后改为整条重写
- **整条重写支持流式输出**（默认开启，仅 Chat Completion API）：边生成边显示在原消息上，不用干等；点右上角的"正在流式改写"提示可随时停止，停止或失败时原文不变。开启主路径预设时，请求体仍由 SillyTavern 完整构建（预设参数、世界书都保留），只是改为流式发送
- **两段式格式修复**：第一段按所选预设模式生成搜索替换块；只有块无法解析或匹配失败时，才用一个独立、无聊天上下文的工具调用整理成结构化编辑。第一段全部成功就不会发第二次请求；修复请求不经过主生成管线，不会改动主对话的请求，也可以在设置里关闭

## 常见问题

**压缩会把原文删掉吗？**
不会。原文只是灰显、不再发给模型，聊天记录里随时能看。不想隐藏的话把勾去掉即可。

**压缩用的是哪个模型？**
默认是你当前连接的模型；开「自定义连接」后则是那里指定的源 + 代理 + 模型。

**改写用的是哪个模型？会带完整上下文吗？**
默认是你当前连接的模型（开「自定义连接」后是那里指定的源 + 代理 + 模型，结构修复请求也一并跟随）。默认开启「使用主路径预设」，走完整的提示词构建管线（预设、世界书、聊天历史），改写指令注入在上下文末尾；关闭后只发送未隐藏的聊天内容和改写指令。「使用主路径预设」这个开关不影响独立的格式修复请求，但格式修复请求会跟随「自定义连接」（开了的话）。

**局部替换模式失败了怎么办？**
如果模型输出的替换块和原文对不上，扩展会尽量容错（忽略首尾空白、空白差异），并默认尝试一次独立的结构化修复；修复后仍完全对不上的块会跳过并提示，一个都没对上则原文保持不动、指令保留在输入框方便重试。也可以在设置里关闭工具修复，或关掉局部替换模式、改用整条重写。
